# StudyOS

> **Building a website helpful for learners and polymaths. A masterpiece to recommend to winners.**

StudyOS is a student productivity web application designed to help learners organize their tasks, track their progress, and build better study habits.

This project is being built from the ground up as a practical software-development project, starting with HTML, CSS, and JavaScript and gradually evolving into a full-stack application.

---

## 🚀 Current Features

- Add new tasks
- Prevent empty tasks
- Automatically clear the input after adding a task
- Delete tasks
- Mark tasks as completed
- Dynamic task creation using JavaScript
- Dynamically created buttons
- CSS styling for dynamically created elements

## 🎯 Project Goals

StudyOS aims to become an all-in-one productivity platform for students, self-learners, and polymaths.

The long-term goal is to combine:

- Task management
- Subject organization
- Personal notes
- Study sessions
- Progress tracking
- Productivity tools
- Personalized learning features

into one simple platform.
